iStoreHub export status is a system record. It does not replace a physical receiving count or change inventory.

Import StoreHub export

  1. In StoreHub Backoffice, open Stock Transfers and choose Export to CSV.
  2. Select “Include item details” for the date range you need.
  3. Upload the file here, review the preview, then confirm.

Repeat imports do not duplicate transfers. Older statuses are skipped, so always upload the newest export.
